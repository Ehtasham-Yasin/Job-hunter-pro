# 🚀 JobHunter Pro

AI-powered career platform for job seekers and recruiters.

JobHunter Pro helps candidates discover opportunities, optimize resumes, prepare for interviews, and track applications while enabling recruiters to post jobs, manage applicants, and streamline hiring workflows.

## ✨ Features

### 👨‍💼 Job Seekers

* AI-powered job recommendations
* Resume Analyzer
* ATS Resume Scoring
* Interview Preparation
* Application Tracking
* Career Insights
* Job Search Dashboard
* Light & Dark Mode

### 🏢 Recruiters

* Recruiter Dashboard
* Post Jobs
* Manage Jobs
* Applicant Tracking
* Hiring Analytics
* Candidate Management

### 🤖 AI Features

* Resume Analysis
* Job Matching
* Cover Letter Generation
* Interview Coaching
* Hiring Insights

## 🛠 Tech Stack

## 🚀 Getting Started

### Install Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm run dev
```

### Start API Server

```bash
npm run api
```

### Prisma

```bash
npx prisma generate
npx prisma migrate dev
```
